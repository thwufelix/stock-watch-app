# 資料來源與免責聲明

## 使用的資料來源

| 用途 | 來源 | 是否需要金鑰 | 備註 |
|---|---|---|---|
| 個股每日收盤價 | [台灣證券交易所 OpenAPI](https://openapi.twse.com.tw/) `STOCK_DAY_ALL` | 不需要 | 只回傳「當天」全市場資料，靠每日排程逐日累積成歷史序列 |
| 相關新聞 | [Google News RSS](https://news.google.com/rss) | 不需要 | 非官方財經資料 API，只是新聞標題/連結彙整，正確性以原新聞來源為準 |
| 產業鏈分工 | 專案內建的 `src/data/industryChains.json` | — | 人工整理的公開常識性資料，非即時資料庫 |

全部都是公開、免費、不需要申請帳號或金鑰的資料源，符合「不花額外費用」的需求。
缺點是：更新頻率較低（一天一次）、沒有官方 SLA 保證穩定性、新聞比對用的是關鍵字搜尋
而非專業的自然語言處理，準確度有限。

## 若未來想升級資料品質

- **股價／財務資料**：可考慮 TEJ（台灣經濟新報，付費，資料最完整）、
  Finnhub / Alpha Vantage（有免費額度但美股為主，台股支援有限）
- **新聞**：可考慮 NewsAPI、財經媒體官方 RSS（如鉅亨網、經濟日報）以取得更穩定的來源
- **推播基礎架構**：若使用者數增加，靠手動貼上 `subscriptions.json` 會不敷使用，
  屆時可以加一個輕量後端（如 Cloudflare Workers 免費額度）改成即時 API 接收訂閱

均線相對位置、新聞關鍵字比對），**不涉及任何人工審核，也不是投資顧問或分析師的
專業判斷**。所有內容僅供個人學習與參考，不構成任何形式的投資建議、勸誘或保證，
投資人應自行蒐集完整資訊並審慎評估風險，盈虧自負。若你將本專案公開分享給他人使用，
請務必保留本聲明。
